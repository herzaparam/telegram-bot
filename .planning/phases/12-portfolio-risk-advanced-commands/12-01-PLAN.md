    2. Create src/risk/correlation.py:
       - Frozen dataclass `CorrelationResult(matrix: dict[str, dict[str, float]], high_pairs: list[tuple[str, str, float]], avg_correlation: float)`
       - `compute_correlation_matrix(price_data: dict[str, pd.Series], window: int = 30) -> CorrelationResult`
         - Build DataFrame of pct_change returns from close prices, tail(window), call .corr()
         - Extract pairs where abs(corr) > 0.8 into high_pairs
         - Compute avg from upper triangle via np.triu_indices
       - `CORR_EMOJI = {"high_pos": "\U0001f534", "med_pos": "\U0001f7e0", "low": "\U0001f7e2", "med_neg": "\U0001f535", "high_neg": "\U0001f7e3"}`
       - `format_correlation_heatmap(result: CorrelationResult) -> str` producing HTML with `<code>` header row of 4-char symbols, emoji cells per row. Diagonal = white square "\u2b1c". Thresholds: >0.7 red, >0.4 orange, >-0.3 green, >-0.7 blue, else purple.

    3. Create src/risk/var.py:
       - Frozen dataclass `VaRResult(daily_var_95: float, daily_var_99: float, weekly_var_95: float, weekly_var_99: float, max_drawdown: float, max_drawdown_start: str, max_drawdown_end: str)`
       - `compute_historical_var(returns: pd.Series, lookback: int = 252) -> VaRResult`
         - Raise ValueError if len(returns) < 60
         - Tail lookback, dropna
         - daily_95 = np.percentile(r, 5), daily_99 = np.percentile(r, 1)
         - Weekly: 5-day rolling sum returns, percentile if >20 points, else daily * sqrt(5)
         - Max drawdown: cumulative = (1+r).cumprod(), running_max = cumulative.cummax(), drawdown = (cumulative - running_max) / running_max, min
         - Round all values to 6 decimal places

    4. Create src/risk/concentration.py:
       - Frozen dataclass `ConcentrationResult(sector_pct: dict[str, float], max_single_pct: float, idr_pct: float, usd_pct: float, asset_count: int)`
       - `compute_concentration(assets: list[dict], sector_map: dict[str, str]) -> ConcentrationResult`
         - assets is list of {"symbol": str, "asset_type": str}
         - Equal-weight: each asset = 100/N percent
         - Sector: group stock assets by sector_map lookup, "unknown" if not found. Crypto gets "crypto" sector
         - idr_pct = count(stock)/total * 100, usd_pct = count(crypto)/total * 100
         - max_single_pct = 100/N (equal weight, so all same)

    5. Create src/risk/stress.py:
       - Frozen dataclass `StressResult(scenario_id: str, scenario_name: str, stock_drawdown: float, crypto_drawdown: float, portfolio_impact: float, duration_days: int)`
       - `STRESS_SCENARIOS` dict with 4 preset scenarios per research:
         - covid_2020: stock=-0.37, crypto=-0.50, duration=30
         - crypto_winter_2022: stock=-0.10, crypto=-0.77, duration=365
         - taper_tantrum_2013: stock=-0.15, crypto=-0.05, duration=90
         - gfc_2008: stock=-0.60, crypto=0.0, duration=365
       - `run_stress_test(assets: list[dict]) -> list[StressResult]`
         - For each scenario, compute weighted portfolio impact: sum(asset_weight * drawdown_for_type) across equal-weighted assets
         - stock assets get stock_drawdown, crypto assets get crypto_drawdown

    6. Create src/risk/metrics.py:
       - Frozen dataclass `RiskMetricsResult(sharpe_ratio: float, sortino_ratio: float, annualized_return: float, annualized_volatility: float)`
       - `compute_risk_metrics(returns: pd.Series, risk_free_rate: float = 0.05, periods_per_year: int = 252) -> RiskMetricsResult`
         - Annualized return = mean(returns) * periods_per_year
         - Annualized vol = std(returns) * sqrt(periods_per_year)
         - Sharpe = (annualized_return - risk_free_rate) / annualized_vol
         - Sortino: downside_std = std(returns[returns < 0]) * sqrt(periods_per_year), sortino = (annualized_return - risk_free_rate) / downside_std
         - Handle zero-vol edge case: return 0.0 for ratios
