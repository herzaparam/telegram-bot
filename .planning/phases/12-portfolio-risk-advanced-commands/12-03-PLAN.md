
    2. Implement `async def run_backtest(symbol: str, period: str) -> dict`:
       - Validate period is in VALID_PERIODS, raise ValueError otherwise
       - Look up Asset by symbol (case-insensitive ilike)
       - Check for cached BacktestResult with same asset_id, period, run_date=today. If found, return cached result as dict
       - Determine backtest date range: end_date = today, start_date = today - timedelta(days=VALID_PERIODS[period])
       - Load ALL price history for this asset up to end_date
       - For each trading day D in [start_date, end_date):
         a. Slice price data to only include rows where time <= D (no look-ahead bias)
         b. Build DataFrame from sliced data
         c. Skip if fewer than 30 price rows (insufficient data for engines)
         d. Run all applicable engines via `_get_engines_for_asset(asset_type)` — instantiate fresh, call analyze(prices_df_slice)
         e. Collect signals as list of Signal objects
         f. Call LLM to produce verdict from signals (simplified prompt, not full decide_stage to avoid DB dependency per day). Use `llm_completion()` with a condensed prompt that includes engine scores and asks for STRONG_BUY/BUY/HOLD/SELL/STRONG_SELL verdict
         g. Record verdict and next-day actual price change
         h. Add 0.5s delay between LLM calls to avoid rate limits
       - Compute summary stats:
         - win_rate: fraction of days where verdict direction matched actual price movement (BUY/STRONG_BUY + price up = win; SELL/STRONG_SELL + price down = win; HOLD = neutral, counted as win if abs(change) < 1%)
         - total_return: sum of daily returns when following signals (BUY: +return, SELL: -return, HOLD: 0)
         - buy_hold_return: (final_price - start_price) / start_price
         - max_drawdown: from cumulative signal-following returns
         - sharpe_ratio: from daily signal-following returns (annualized)
       - Store result in BacktestResult table via pg_insert with on_conflict_do_update on (asset_id, period, run_date)
       - Return result as dict: {"symbol", "period", "win_rate", "total_return", "buy_hold_return", "max_drawdown", "sharpe_ratio", "days_tested", "status": "complete"}

    3. Implement `__main__` block:
       ```python
       if __name__ == "__main__":
           parser = argparse.ArgumentParser(description="Run historical backtest")
           parser.add_argument("--asset", required=True, help="Asset symbol")
           parser.add_argument("--period", required=True, choices=["7d", "30d", "90d"])
           args = parser.parse_args()

           result = asyncio.run(run_backtest(args.asset, args.period))
           # Print JSON to stdout for the bot handler to read
           print(json.dumps(result))
       ```
