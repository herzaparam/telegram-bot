    **Create src/data/validation.py:**

    Import: `math`, `structlog`, `OHLCVRow` from `src.data.base`, `date` from `datetime`

    `logger = structlog.get_logger(__name__)`

    1. `@dataclass` class `ValidationResult`:
       - `valid: list[OHLCVRow]`
       - `rejected: list[tuple[OHLCVRow, str]]` (row + reason string)

    2. `def validate_rows(rows: list[OHLCVRow], asset_symbol: str = "") -> ValidationResult`:
       - Iterate rows
       - For each row, check:
         - `open`, `high`, `low`, `close`, `volume` are not None
         - None of those fields are NaN (use `math.isnan()`)
         - `high >= low` (sanity check)
         - `volume >= 0`
       - Valid rows go to `valid` list
       - Invalid rows go to `rejected` list with reason string like `"open is NaN"`, `"volume is None"`, `"high < low"`
       - Log each rejected row: `logger.warning("ohlcv_row_rejected", asset=asset_symbol, time=str(row.time), reason=reason)`
       - Return ValidationResult

    3. `def validate_date_coverage(rows: list[OHLCVRow], start: date, end: date, asset_symbol: str = "") -> list[date]`:
       - Extract unique dates from rows (row.time.date())
       - Generate expected business days between start and end (simple: exclude Saturday=5, Sunday=6)
       - Find missing dates (expected - actual)
       - If missing dates, log: `logger.warning("ohlcv_date_gaps", asset=asset_symbol, missing_count=len(missing), missing_dates=[str(d) for d in sorted(missing)[:5]])`
       - Return list of missing dates
