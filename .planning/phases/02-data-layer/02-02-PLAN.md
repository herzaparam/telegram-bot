    - `async def fetch(self, asset_id: int, symbol: str, start: date, end: date) -> list[OHLCVRow]`:
      - Try ccxt first, fall back to CoinGecko on any exception
      - ccxt path:
        - `exchange = ccxt.binance({"enableRateLimit": True})`
        - Convert start date to milliseconds: `int(datetime.combine(start, time.min, tzinfo=timezone.utc).timestamp() * 1000)`
        - Paginate: call `exchange.fetch_ohlcv(symbol, "1d", since=start_ms, limit=1000)` in a loop, advancing `since` until past end date or empty result
        - MUST close exchange: `await exchange.close()` in finally block
        - Convert each `[timestamp_ms, open, high, low, close, volume]` to OHLCVRow with source="ccxt"
        - Normalize timestamp: `datetime.fromtimestamp(ts / 1000, tz=timezone.utc)`
      - CoinGecko fallback path:
        - Use httpx async client
        - Map symbol to CoinGecko ID: `{"BTC/USDT": "bitcoin", "ETH/USDT": "ethereum", "SOL/USDT": "solana"}` (hardcoded mapping, extensible)
        - Call `GET /coins/{id}/market_chart/range?vs_currency=usd&from={start_ts}&to={end_ts}`
        - Extract prices from `response["prices"]` and volumes from `response["total_volumes"]`
        - Construct OHLCVRow with source="coingecko"
        - Note: CoinGecko market_chart returns [timestamp_ms, value] pairs; prices list gives close values, need to derive OHLC from daily granularity (for daily candles, open=close of previous or same as close for first)
        - Simpler approach: use `/coins/{id}/ohlc?days=N&vs_currency=usd` which returns [timestamp, open, high, low, close] but NO volume. Set volume=0 and tag source="coingecko" so downstream knows volume is unreliable.
      - Retry: `@retry(stop=stop_after_attempt(3), wait=wait_exponential(multiplier=1, min=2, max=30), retry=retry_if_exception_type((ccxt.NetworkError, ccxt.ExchangeNotAvailable, TimeoutError)), reraise=True)` on ccxt call
    - `async def fetch_hourly(self, asset_id: int, symbol: str, start: date, end: date) -> list[OHLCVRow]`:
      - Same as fetch but with timeframe="1h"
      - Only for crypto, used for price_history_hourly
      - Source="ccxt", no CoinGecko fallback for hourly

    **Create src/data/staleness.py:**

    Import: `datetime`, `structlog`, `date` from datetime

    `logger = structlog.get_logger(__name__)`

    1. `@dataclass` class `StalenessResult`:
       - `asset_symbol: str`
       - `asset_type: str`
       - `is_stale: bool`
       - `latest_data_time: datetime | None`
       - `expected_by: datetime`
       - `reason: str`

    2. `def check_staleness(asset_symbol: str, asset_type: str, latest_data_time: datetime | None, now: datetime | None = None) -> StalenessResult`:
       - If `now` is None, use `datetime.now(timezone.utc)`
       - For `asset_type == "stock"` (IDX):
         - Find the last trading day: start from today, walk backwards skipping Saturday (weekday==5) and Sunday (weekday==6)
         - Stale if `latest_data_time` is None or `latest_data_time.date() < last_trading_day`
         - Expected by: last trading day at 23:59 UTC
         - Reason: `"No data for last trading day {last_trading_day}"` or `"No data at all"`
       - For `asset_type == "crypto"`:
         - Stale if `latest_data_time` is None or `(now - latest_data_time) > timedelta(hours=24)`
         - Expected by: `now - timedelta(hours=24)`
         - Reason: `"No data in last 24 hours"` or `"No data at all"`
       - Log if stale: `logger.warning("asset_stale", asset=asset_symbol, type=asset_type, reason=reason)`
       - Return StalenessResult
