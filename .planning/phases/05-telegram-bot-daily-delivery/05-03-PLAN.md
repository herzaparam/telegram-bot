```python
"""Pipeline report delivery stage.

Formats the daily signal report and sends to Telegram via httpx.
NOT a StageFunc -- runs after all pipeline stages complete (D-15).
Uses httpx for Telegram API, never imports python-telegram-bot (D-16).
"""
from __future__ import annotations
import httpx
import structlog
from collections import Counter
from datetime import date
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession
from src.config import settings
from src.db.models import Asset, DailyDecision, Watchlist
from src.report.formatter import format_asset_card, format_report_header, split_report

logger = structlog.get_logger(__name__)
TELEGRAM_API = "https://api.telegram.org/bot{token}/sendMessage"
```

Functions to implement:

`async def send_telegram_message(chat_id: str, text: str, token: str) -> bool`:
- POST to TELEGRAM_API.format(token=token) with JSON body: `{"chat_id": chat_id, "text": text, "parse_mode": "HTML"}`
- Use `async with httpx.AsyncClient(timeout=10.0) as client:`
- On 200: return True
- On 429 (rate limit): read `retry_after` from response JSON, `await asyncio.sleep(retry_after)`, retry once, return result
- On other error: log warning with status code and response text, return False

`async def send_daily_report(session: AsyncSession, run_date: date, stage_results: list | None = None) -> None`:
- If `settings.telegram_bot_token.get_secret_value()` is empty: log warning "no_bot_token", return
- Get chat IDs: `[cid.strip() for cid in settings.telegram_chat_id.split(",") if cid.strip()]`
- If no chat IDs: log warning "no_chat_ids", return
- Query watchlist asset IDs: `select(Watchlist.asset_id)`
- If empty: log info "empty_watchlist_no_report", return
- Query decisions for run_date joined with assets, filtered to watchlist asset IDs:
  ```python
  stmt = (
      select(DailyDecision, Asset)
      .join(Asset, DailyDecision.asset_id == Asset.id)
      .where(DailyDecision.date == run_date)
      .where(DailyDecision.asset_id.in_(select(Watchlist.asset_id)))
      .order_by(Asset.symbol)
  )
  ```
- If no decisions: send "no signals available" message to each chat ID, return
- Build sentiment distribution: `Counter(d.verdict for d, a in results)`
- Collect risk warnings from decisions with non-null risk_warning (deduplicate)
- Check stage_results for failed assets: if any stage has status "partial" or "failed", add failure notice per D-18
- Format header with `format_report_header(str(run_date), len(results), dict(distribution), risk_warnings)`
- Format each asset card with `format_asset_card(a.symbol, a.name or a.symbol, d.verdict, float(d.score or 0), float(d.confidence or 0), d.reasoning or "")`
- Split with `split_report(header, cards)`
- For each chat_id, for each message chunk: call `send_telegram_message(chat_id, chunk, token)`
- Log info "report_sent" with chat_id count and message count

`async def send_pipeline_failure_alert(run_date: date) -> None`:
- If no bot token or no chat IDs: return
- Send per UI-SPEC full pipeline failure message:
  ```
  warning_emoji <b>Pipeline Failed</b>

  Today's signal report could not be generated. The team has been notified.
  ```
- Send to all configured chat IDs
