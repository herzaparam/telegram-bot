**Constants:**

```python
import html
MAX_MESSAGE_LENGTH = 4096
VERDICT_EMOJI: dict[str, str] = {
    "STRONG BUY": "\U0001f7e2\U0001f7e2",  # green green
    "BUY": "\U0001f7e2",                     # green
    "HOLD": "\U0001f7e1",                     # yellow
    "SELL": "\U0001f534",                     # red
    "STRONG SELL": "\U0001f534\U0001f534",    # red red
}
DEFAULT_EMOJI = "\u26aa"  # white circle for unknown/fallback
```

**Functions:**

`format_asset_card(symbol: str, name: str, verdict: str, score: float, confidence: float, reasoning: str) -> str`
  - Per UI-SPEC Asset Card format:
    ```
    {emoji} <b>{SYMBOL}</b> ({name})
       {VERDICT} | Score: {+0.00} | Conf: {00%}
       <i>{reasoning truncated to 100 chars at word boundary}...</i>
    ```
  - Score formatted with `f"{score:+.2f}"`, confidence as `f"{confidence:.0%}"`
  - Truncate reasoning: if >100 chars, split at last space before 100, append "..."
  - Use `html.escape()` on symbol, name, reasoning

`format_asset_detail(symbol: str, name: str, verdict: str, score: float, confidence: float, reasoning: str, key_factors: dict | None, risk_warning: str | None) -> str`
  - Per UI-SPEC Single-Asset Detail format with full reasoning, key factors, risk warning sections
  - No truncation on reasoning

`format_report_header(run_date: str, total: int, distribution: dict[str, int], risk_warnings: list[str]) -> str`
  - Per UI-SPEC Report Header format
  - Omit risk warnings line if list is empty
  - Only show non-zero categories in distribution

`split_report(header: str, asset_cards: list[str]) -> list[str]`
  - Per D-08: split at asset card boundaries, never mid-card
  - First message: full header + as many cards as fit within 4096
  - Subsequent messages: `<b>... continued ({N})</b>` mini-header + more cards
  - Each returned string <= MAX_MESSAGE_LENGTH

`format_watchlist_message(assets: list[tuple[str, str, str]]) -> str`
  - Takes list of (symbol, name, exchange) tuples
  - Per UI-SPEC /watchlist Display format: numbered list with bold symbols
  - Empty list: returns empty state message per UI-SPEC
