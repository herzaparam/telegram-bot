       - `_hurst_exponent(prices: np.ndarray) -> float`: R/S analysis implementation from RESEARCH.md. Use sub-series sizes [16, 32, 64, 128, 256]. Log-log regression for slope. Return 0.5 if insufficient data or <2 valid sizes. Clip to [0, 1].

       - `_ou_half_life(prices: np.ndarray) -> float`: OLS regression of delta_y on y_lag from RESEARCH.md. Return float("inf") if lambda >= 0 (not mean-reverting). Use np.linalg.lstsq.

       - `_arima_forecast(prices: np.ndarray) -> tuple[float, float, float]`: Wrap pmdarima.auto_arima with start_p=1, start_q=1, max_p=5, max_q=5, max_d=2, seasonal=False, stepwise=True, suppress_warnings=True, error_action="ignore". Return (forecast, lower_ci, upper_ci) at 95% confidence. Raises ValueError on failure (caller catches).

       - `_roc_to_score(roc_5: float, roc_10: float, roc_20: float) -> float`: Weighted average of ROC values mapped to [-1, 1]. ROC > 5% -> +0.7, ROC > 2% -> +0.4, ROC > 0 -> +0.1, etc. Weight: roc_5 * 0.5, roc_10 * 0.3, roc_20 * 0.2.

       - `_zscore_to_score(z_20: float, z_50: float) -> float`: Z-score below -2 -> +0.8 (oversold), below -1 -> +0.4, between -1 and 1 -> 0.0, above 1 -> -0.4, above 2 -> -0.8. Average z_20 and z_50 scores.

       - `_arima_to_score(current_price: float, forecast: float, lower_ci: float, upper_ci: float) -> float`: If forecast > current + (upper - current)*0.3 -> bullish. If forecast < current - (current - lower)*0.3 -> bearish. Scale by confidence interval width.

    3. `class QuantitativeEngine(BaseEngine)`:
       - `category` property returns `"quantitative"`
       - `analyze(self, asset_id, asset_symbol, df)` method:
         a. If df empty or len(df) < MIN_DAYS_BASIC: return Signal with score=0, confidence=0, reasoning="Insufficient data for quantitative analysis (need >= 25 trading days)"
         b. Extract close prices as numpy array
         c. Compute ROC at 5, 10, 20 days (pct_change or manual)
         d. Compute z-scores: (close - rolling_mean) / rolling_std for 20-day and 50-day windows
         e. Track skipped indicators list
         f. If len(df) >= MIN_DAYS_FULL:
            - Compute Hurst exponent
            - Compute OU half-life
            - Try ARIMA forecast (catch ValueError/Exception, add to skipped)
            - Determine regime: H > 0.55 = "trending", H < 0.45 = "mean_reverting", else "indeterminate"
         g. Else: skip ARIMA, Hurst, OU; regime = "insufficient_data"
         h. Compute component scores:
            - momentum_score = _roc_to_score(roc_5, roc_10, roc_20)
            - reversion_score = _zscore_to_score(z_20, z_50)
            - arima_score = _arima_to_score(...) if computed, else 0.0
         i. Apply regime-based weighting:
            - If trending (H>0.55): momentum * 0.50, reversion * 0.20, arima * 0.30
            - If mean-reverting (H<0.45): momentum * 0.20, reversion * 0.50, arima * 0.30
            - If indeterminate or insufficient: use config weights (weight_momentum, weight_mean_reversion, weight_arima)
         j. Clamp score to [-1.0, +1.0]
         k. Confidence = base_agreement * (1 - penalty)
            - base_agreement = how many components agree with final direction / total components
            - penalty = 0.15 per skipped component (arima, hurst), capped at 0.4
         l. Reasoning: "Regime: {regime} (H={hurst:.2f}). ROC(5d)={roc_5:.1%}, Z-score(20d)={z_20:.2f}. {ARIMA forecast if available}. Momentum weighted {weight}."
         m. Wrap entire method in try/except, return score=0/confidence=0 on failure
