```python
@dataclass(frozen=True)
class Signal:
    category: str
    score: float        # -1.0 to +1.0
    confidence: float   # 0.0 to 1.0
    reasoning: str
    indicators: dict
    data_quality: dict

class BaseEngine(ABC):
    @abstractmethod
    def analyze(self, asset_id: int, asset_symbol: str, df: pd.DataFrame) -> Signal: ...
    @property
    @abstractmethod
    def category(self) -> str: ...
    @property
    def supports_stocks(self) -> bool: return True
    @property
    def supports_crypto(self) -> bool: return True
```

**DCF computation (per D-11, D-14):**
```python
def _compute_dcf(
    fcf: float, growth_rate: float, wacc: float,
    shares_outstanding: float, projection_years: int = 5,
    terminal_growth: float = 0.03,
) -> float:
```
- Two-stage model: 5 years explicit projection + Gordon Growth terminal value
- Guard: if shares_outstanding <= 0 or wacc <= terminal_growth, return 0.0
- Terminal value: `fcf * (1+growth)^years * (1+terminal_growth) / (wacc - terminal_growth)`
- Discount all to present value
- Return enterprise_value / shares_outstanding

**WACC computation (per D-11):**
```python
def _compute_wacc(
    risk_free_rate: float,  # BI rate or US 10Y
    beta: float,           # Stock beta (from yfinance or default 1.0)
    equity_risk_premium: float = 0.065,  # Indonesia ERP ~6.5%
    debt_ratio: float = 0.0,
    cost_of_debt: float = 0.0,
    tax_rate: float = 0.22,  # Indonesia corporate tax
) -> float:
```
- CAPM: cost_of_equity = risk_free_rate + beta * equity_risk_premium
- WACC = cost_of_equity * (1 - debt_ratio) + cost_of_debt * (1 - tax_rate) * debt_ratio
- Clamp result to [0.05, 0.25] range for sanity

**Peer comparison (per D-12):**
```python
def _compute_peer_score(
    stock_metrics: dict[str, float],  # {"pe": 10, "pb": 1.5, "ev_ebitda": 8}
    sector_averages: dict[str, float],  # {"pe": 15, "pb": 2.0, "ev_ebitda": 12}
) -> tuple[float, str]:
```
- Compare each metric. Lower P/E, P/B, EV/EBITDA vs sector = cheaper = positive score
- For each metric: if stock < sector * 0.85 -> "cheap", > sector * 1.15 -> "expensive", else "fair"
- Average across available metrics to get composite peer score [-1, +1]
- Return (score, rank_label) where rank_label is overall "cheap"/"fair"/"expensive"

**Scenario analysis (per D-14):**
```python
def _compute_scenarios(
    current_price: float, fair_value: float,
    cagr: float, std_dev: float,
) -> dict[str, dict[str, float]]:
```
- Bull (25%): fair_value adjusted by (cagr + std_dev)
- Base (50%): fair_value (unchanged)
- Bear (25%): fair_value adjusted by (cagr - std_dev)
- Each entry: {"value": float, "return_pct": float, "weight": float}
- Weighted return = 0.25 * bull_return + 0.50 * base_return + 0.25 * bear_return

  4. If neither available, return score=0, confidence=0
  5. Return Signal with combined reasoning
