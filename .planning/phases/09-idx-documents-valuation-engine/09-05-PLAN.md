**Helper: format_idr** (for consistent currency formatting):
```python
def format_idr(value: float) -> str:
    """Format IDR value with unit abbreviation. Rp 2.1T, Rp 450B, Rp 12.3M"""
    abs_val = abs(value)
    sign = "-" if value < 0 else ""
    if abs_val >= 1_000_000_000_000:
        return f"{sign}Rp {abs_val / 1_000_000_000_000:.1f}T"
    if abs_val >= 1_000_000_000:
        return f"{sign}Rp {abs_val / 1_000_000_000:.0f}B"
    if abs_val >= 1_000_000:
        return f"{sign}Rp {abs_val / 1_000_000:.1f}M"
    return f"{sign}Rp {abs_val:,.0f}"
```

Implementation:

2. If no args: reply with "Please specify an IDX stock symbol. Example: /valuation BBCA" (UI-SPEC copy)

Read from a valuation_cache or compute from raw financial_data using local helper functions that replicate the math WITHOUT importing engine modules)
   - IMPORTANT: To respect the two-process boundary, the bot handler should query pre-computed valuation results. Add a simple `valuation_results` JSON column to `FinancialDoc` or store the computed valuation as a Signal in the signals table during pipeline analyze stage. The bot reads the stored Signal for category="valuation" from the signals table.

CRITICAL two-process boundary approach: The bot reads the **signals table** for `category="valuation"` (stored during analyze_stage by ValuationEngine).
