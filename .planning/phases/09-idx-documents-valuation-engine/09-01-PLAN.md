Key implementation details (per D-01, D-02, D-03, D-04):

```python
IDX_REPORT_URL = "https://idx.co.id/umbraco/Surface/ListedCompany/GetFinancialReport"
_FETCH_INTERVAL_DAYS = 7  # Weekly check per D-03

PERIODE_MAP = {
    "tw1": ("quarterly", "Q1"),
    "tw2": ("quarterly", "Q2"),
    "tw3": ("quarterly", "Q3"),
    "tahunan": ("annual", "FY"),
}
```

1. Check if last fetch was within 7 days by querying `FinancialDoc` for this asset's most recent `downloaded_at`. If recent, skip (log "skipping, fetched recently").
2. Strip ".JK" suffix from `asset.yfinance_symbol` to get the IDX emiten code (e.g., "BBCA.JK" -> "BBCA").
3. For current year and previous year, iterate over all 4 `periode` values and query `IDX_REPORT_URL` with params: `indexFrom=0, pageSize=10, year={year}, reportType=rdf, periode={periode}, kodeEmiten={code}`.
4. Set headers: `{"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"}`.
5. Parse JSON response. `data.get("Results", [])` returns report entries. Each entry has `Attachments` list with `File_Path` URLs.
6. Filter attachments for financial report keywords in filename.
7. Download PDF to `data/financial_docs/{SYMBOL}/{period}.pdf` using httpx streaming.
8. Create `FinancialDoc` record with `parse_status="pending"`.
9. All HTTP calls wrapped in try/except -- on failure, log error via structlog (per D-05), do not raise.
10. Use `asyncio.sleep(1.0)` between requests to avoid rate limiting.

Use `httpx.AsyncClient` with timeout=30.0 for all requests.
