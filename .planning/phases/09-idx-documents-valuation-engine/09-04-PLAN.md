Add a new function `_fetch_and_parse_docs(session: AsyncSession, asset: Asset) -> None`:
1. Call `await fetch_idx_docs(session, asset)` to download any new PDFs
2. **On exception during fetch_idx_docs (per D-05):** catch the exception, log error via structlog, and send a Telegram alert to the user using the same httpx pattern from src/data/report.py:
   ```python
   try:
       await fetch_idx_docs(session, asset)
   except Exception as exc:
       logger.error("idx_doc_fetch_failed", asset=asset.symbol, error=str(exc))
       # Send Telegram alert per D-05
       token = settings.telegram_bot_token.get_secret_value()
       chat_id = settings.telegram_chat_id
       if token and chat_id:
           alert_text = f"IDX doc fetch failed for {asset.symbol}: {exc}"
           url = f"https://api.telegram.org/bot{token}/sendMessage"
           try:
               async with httpx.AsyncClient(timeout=10.0) as client:
                   await client.post(url, json={"chat_id": chat_id, "text": alert_text})
           except Exception:
               logger.warning("telegram_alert_failed", asset=asset.symbol)
   ```
3. Query `FinancialDoc` for this asset where `parse_status = "pending"`
4. For each pending doc:
   a. Call `result = await parse_financial_doc(doc.file_path, asset.symbol)`
   b. If result is None: set `doc.parse_status = "failed"`, continue
   c. For each field in result, create a `FinancialData` row:
      - metric_name = field key (e.g., "revenue", "net_profit")
      - metric_value = numeric value (for numeric fields)
      - metric_text = text value (for management_outlook)
      - period = result["period"]
      - period_date = derive from period string (e.g., "Q3 2025" -> 2025-09-30)
   d. Set `doc.parse_status = "parsed"`, `doc.parsed_at = datetime.now(UTC)`
5. Wrap the parse loop in try/except -- on failure, log error, do not raise

```python
# QoQ alert thresholds (per D-21 and UI-SPEC)
QOQ_THRESHOLDS = {
    "gross_margin": 0.03,      # 3 percentage points
    "operating_margin": 0.03,
    "net_margin": 0.03,
    "revenue": 0.10,           # 10% change
    "net_profit": 0.10,
    "total_debt": 0.15,        # 15% change
    "operating_cash_flow": 0.15,
    "capex": 0.15,
}

@dataclass(frozen=True)
class QoQAlert:
    metric_name: str
    current_value: float
    previous_value: float
    change: float  # absolute change for margins (pp), percentage for others
    is_percentage_point: bool  # True for margins, False for absolute metrics

def detect_qoq_changes(financial_data: list[dict]) -> list[QoQAlert]:
    """Detect significant QoQ ratio changes.

    Args:
        financial_data: List of period dicts ordered by period_date DESC.
            At least 2 periods needed for comparison.

    Returns:
        List of up to 2 most significant QoQAlert objects.
    """
```

Implementation:
1. If less than 2 periods, return empty list
2. Take latest (index 0) and previous (index 1) periods
3. For each metric in QOQ_THRESHOLDS:
   - For margin metrics (gross_margin, operating_margin, net_margin): compute absolute difference in percentage points
   - For other metrics (revenue, net_profit, etc.): compute percentage change
   - If change exceeds threshold, create QoQAlert
4. Sort alerts by magnitude of change (descending)
5. Return top 2 alerts only (per UI-SPEC rule)
