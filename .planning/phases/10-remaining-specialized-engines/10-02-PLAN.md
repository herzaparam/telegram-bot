   - Final score = 0.4 * volume_spike_score + 0.3 * gap_score + 0.3 * divergence_score (capped [-1, 1])

3. Wavelet decomposition using PyWavelets:
   ```python
   import pywt
   close_arr = df["close"].values
   coeffs = pywt.wavedec(close_arr, "db4", level=3)
   # Level 1 (cD1): noise/short-term
   # Level 2 (cD2): medium-term trend
   # Level 3 (cD3): longer-term trend
   # Approximation (cA3): overall trend direction
   ```
   - Compute energy ratio: sum(cA3^2) / sum(all_coeffs^2) -- high energy in approximation = strong trend
   - Compute trend direction from last few cA3 values (positive slope = bullish)
4. Scoring:
   - hurst_score: if H > 0.55, trending -> use wavelet trend direction as score basis (slope of cA3 * 2, capped [-1, 1])
   - hurst_score: if H < 0.45, mean-reverting -> current Z-score of close vs 20-day mean, inverted (high Z = bearish for mean-reverting)
   - hurst_score: if random walk -> score near 0
   - wavelet_score: energy_ratio > 0.6 strengthens the signal (+0.2 to abs(score)), energy_ratio < 0.3 weakens (-0.1)
   - Final score = hurst_score adjusted by wavelet_score, capped [-1, 1]
5. Confidence: 0.2 base + 0.2 * abs(H - 0.5) * 4 (stronger regime = higher confidence) + 0.1 * energy_ratio, capped [0, 0.7]
6. indicators: {"hurst_exponent": H, "regime": "trending"/"mean_reverting"/"random", "wavelet_energy_ratio": ..., "wavelet_trend_slope": ..., "fractal_dimension": 2 - H}
