**src/ml/features.py (per D-01):**
Feature engineering from OHLCV data. No external feature sources.

```python
def extract_features(df: pd.DataFrame, min_rows: int = 60) -> np.ndarray | None:
```

Implementation:
1. Guard: if len(df) < min_rows, return None
2. Extract close and volume series from df
3. Compute features (all from price/volume only per D-01):
   - Returns at horizons [1, 3, 5, 10, 20] days: close[-1] / close[-1-d] - 1
   - Volatility at windows [5, 10, 20]: std of log returns over window
   - RSI-14: standard RSI calculation (gain/loss rolling 14)
   - Volume ratio: vol[-1] / mean(vol[-20:])
   - MACD: ema12 - ema26
   - MACD signal: ema9 of MACD
   - MACD histogram: MACD - signal
   - Bollinger %B: (close - lower) / (upper - lower) with 20-period, 2-std
   - Lagged close ratios at [1, 2, 3, 5] days
   - Average True Range (ATR) 14-period normalized by close
   - On Balance Volume (OBV) 20-day slope
4. Total features: 5 (returns) + 3 (vol) + 1 (RSI) + 1 (vol_ratio) + 3 (MACD) + 1 (BB%B) + 4 (lags) + 1 (ATR) + 1 (OBV) = 20 features
5. Return np.array of shape (1, 20) dtype float32
6. Handle NaN: replace with 0.0 (safe default for tree models)

Also provide:

**src/engines/ml_ai.py (per D-02, D-03, D-05, D-06, D-22):**
Create MLAIEngine extending BaseEngine. Category "ml_ai". Both supports_stocks and supports_crypto True.

Constructor: `__init__(self, asset_type: str = "stock")` -- determines which model files to load (per D-03).

analyze() implementation:
1. Extract features using `from src.ml.features import extract_features`
2. If features is None (insufficient data), return score=0/confidence=0
3. Run XGBoost inference (lazy load per D-22):
   ```python
   import onnxruntime as ort  # Lazy import
   model_path = os.path.join(MODEL_DIR, f"xgboost_{self._asset_type}.onnx")
   if not os.path.exists(model_path):
       return Signal(category="ml_ai", score=0.0, confidence=0.0,
                     reasoning="Model not trained yet. Run: python -m src.ml.train_xgboost",
                     indicators={}, data_quality={"model_missing": True})
   session = ort.InferenceSession(model_path, providers=["CPUExecutionProvider"])
   try:
       input_name = session.get_inputs()[0].name
       outputs = session.run(None, {input_name: features})
       xgb_pred = float(outputs[0][0])
       xgb_prob = float(outputs[1][0][1]) if len(outputs) > 1 else 0.5
   finally:
       del session  # Explicit release per D-22
   ```
4. Run LSTM inference (same lazy pattern). If LSTM model missing, use XGBoost only (100% weight).
5. Ensemble per D-06:
   - If both models: score = 0.6 * xgb_pred + 0.4 * lstm_pred
   - If XGBoost only: score = xgb_pred
   - Confidence = min(xgb_prob, lstm_prob) if both, else xgb_prob * 0.8
6. Map score to [-1, 1] range (tanh capping)
7. Wrap in try/except: any exception returns score=0/confidence=0
8. indicators: {"xgboost_pred": ..., "xgboost_prob": ..., "lstm_pred": ..., "lstm_prob": ..., "ensemble_score": ..., "asset_type": ...}
9. data_quality: {"models_loaded": ["xgboost", "lstm"] or subset, "feature_count": 20}

MODEL_DIR = os.path.join(os.path.dirname(__file__), "..", "ml", "models")

**src/ml/train_lstm.py (per D-02, D-03, D-04):**
CLI training script. Run as: `python -m src.ml.train_lstm --asset-type stock`

Implementation:
1. Parse args: same as XGBoost
2. Load and feature-extract same as XGBoost
3. Reshape for LSTM: sequences of 60 days -> predict next day
4. Build LSTM model using torch:
   ```python
   import torch
   import torch.nn as nn
   class LSTMModel(nn.Module):
       def __init__(self, input_size, hidden_size=64, num_layers=2):
           super().__init__()
           self.lstm = nn.LSTM(input_size, hidden_size, num_layers, batch_first=True)
           self.fc = nn.Linear(hidden_size, 2)  # direction + magnitude
       def forward(self, x):
           out, _ = self.lstm(x)
           return self.fc(out[:, -1, :])
   ```
5. Train: Adam optimizer, lr=0.001, BCEWithLogitsLoss for direction, MSELoss for magnitude
6. Export to ONNX:
   ```python
   dummy_input = torch.randn(1, 60, n_features)
   torch.onnx.export(model, dummy_input, output_path, input_names=["input"], output_names=["prediction", "probability"], opset_version=18)
   ```
7. Print training metrics
8. Save to: src/ml/models/lstm_{asset_type}.onnx

Both scripts:
- Use `if __name__ == "__main__":` with argparse
- Print clear usage instructions at start
- Handle missing data gracefully (skip assets with <200 days of history)
- Note: torch is a dev dependency only. The training scripts are manual CLI tools per D-02. Production inference uses only onnxruntime.
