# Phase 11 — UI Design Contract

> Visual and interaction contract for Telegram message formatting. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Platform note:** This project has no web frontend. All UI is Telegram bot messages using HTML parse_mode. The design contract defines message structure, formatting patterns, emoji usage, and copywriting for three new commands (`/discover`, `/duediligence`, `/compare`) and one new daily report section ("New Opportunities").

## Spacing Scale

Not applicable -- Telegram controls text rendering. Spacing is achieved through blank lines and indentation.

| Token | Value | Usage |
|-------|-------|-------|
| line-break | `\n` | Separates fields within a section |
| section-break | `\n\n` | Separates cards or major sections |

Exceptions: none

## Typography

Telegram HTML supports `<b>`, `<i>`, `<code>`, `<pre>`, `<a>`, `<u>`, `<s>`. No font size or weight control.

| Role | Tag | Usage |
|------|-----|-------|
| Heading | `<b>` | Section titles, asset symbols, metric labels |
| Body | plain text | Values, descriptions, reasoning |
| Emphasis | `<i>` | Reasoning text, secondary explanations |
| Code | `<code>` | Ticker symbols in inline references, error messages |
| Strikethrough | `<s>` | Not used in this phase |

## Message Format Templates

### Discovery Card (used in /discover and daily report)

```
{trigger_emoji} <b>{SYMBOL}</b> ({name}) [{asset_type}]
   Score: {0.00} | Price: {price} ({+change%})
   Triggers: {trigger1_emoji} {trigger1_name}, {trigger2_emoji} {trigger2_name}
```

Example:
```
\U0001f4c8 <b>ACES.JK</b> (Ace Hardware) [stock]
   Score: 0.82 | Price: Rp 1,250 (+8.5%)
   Triggers: \U0001f4c8 Volume 3.2x, \U0001f680 52w High
```

### /discover Full Response

```
<b>\U0001f50d Today's Discoveries</b>
{scan_date}

{card_1}

{card_2}

{card_3}

{card_4}

{card_5}
```

### /duediligence Full Response

```
<b>\U0001f4ca Due Diligence: {SYMBOL}</b>
{name} | Sector: {sector}

<b>Sector Ranking</b>
  P/E: {value} ({emoji} {vs_median})
  P/B: {value} ({emoji} {vs_median})
  ROE: {value}% ({emoji} {vs_median})
  Net Margin: {value}% ({emoji} {vs_median})
  Debt/Equity: {value} ({emoji} {vs_median})

<b>Management Quality</b>
  {quality_emoji} {label} ({score}/1.00)
  Revenue CAGR: {cagr}%
  ROE Trend: {trend_description}

<b>Ownership</b>
  Top Holders:
  - {holder_name}: {pct}% {change_emoji} ({delta})
  - {holder_name}: {pct}% {change_emoji} ({delta})
  Last updated: {date}

<b>Competitive Position</b>
  Sector rank: #{rank} of {total} ({metric})
  Moat indicators: {moat_summary}
```

<b>\U0001f4ca Sector Comparison</b>

<pre>

-----------|---------|---------|---------|-------
P/E        | {val}\U0001f451 | {val}   | {val}   | {med}
P/B        | {val}   | {val}\U0001f451 | {val}   | {med}
ROE %      | {val}   | {val}   | {val}\U0001f451 | {med}
Net Mgn %  | {val}   | {val}   | {val}   | {med}

### Daily Report "New Opportunities" Section

Appended after the news digest section (last in report), before the report footer:

```
---

<b>\U0001f50d New Opportunities</b>

{discovery_card_1}

{discovery_card_2}

...up to 5 cards
```

If zero discoveries, omit this section entirely.

## Formatting Rules

1. **HTML escape all user-derived data** using `html.escape()` before embedding in templates. Applies to: ticker symbols, company names, holder names, sector names.

2. **Reasoning truncation** at 100 characters at word boundary with `...` suffix, matching existing `_truncate_reasoning()` in formatter.py.

3. **Message length splitting** via existing `split_report()` for daily report. Individual command responses (`/discover`, `/duediligence`, `/compare`) should fit within 4096 characters. If `/compare` with 5 symbols exceeds limit, split into two messages.

4. **Number formatting:**
   - IDX prices: `Rp {x:,.0f}` (no decimals, comma separators)
   - Crypto prices: `${x:,.2f}` (2 decimals for USD)
   - Percentages: `{x:.1f}%` (1 decimal)
   - Scores: `{x:.2f}` (2 decimals)
   - Ratios (P/E, P/B, D/E): `{x:.1f}` (1 decimal)

5. **Sector median comparison labels:**
   - More than 10% above median: `above` with green emoji
   - Within 10% of median: `at median` with yellow emoji
   - More than 10% below median: `below` with red emoji
   - For D/E ratio, invert the coloring (lower is better)

6. **Crown emoji placement** in `/compare`: placed after the best value in each row. "Best" means highest for ROE, Net Margin, Rev CAGR; lowest for P/E, P/B, D/E.

7. **Trigger emoji mapping** in discovery cards: show the emoji for the highest-scoring trigger first, then secondary triggers. Maximum 3 triggers shown per card.
