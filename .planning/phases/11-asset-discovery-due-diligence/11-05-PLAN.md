```python
"""Handler for /discover command (TBOT-06).

Shows today's top discovery candidates. Reads from discovery_candidates table.
Does NOT import pipeline/scanner modules (two-process boundary).
"""
```

- Import: `is_authorized`, `async_session_factory`, `DiscoveryCandidate`, `format_discovery_card` from formatter
- `async def discover_handler(update, context)`:
  - Auth check with `is_authorized`
  - Log command
  - Query DiscoveryCandidate for today's date (`scan_date == date.today()`), ordered by `composite_score DESC`, limit 5
  - If no results, reply with empty state: `"\U0001f50d No new opportunities found today.\n\nThe scanner checks all IHSG stocks and top 100 crypto daily. Try again tomorrow."` per UI-SPEC
  - Otherwise, build header `"<b>\U0001f50d Today's Discoveries</b>\n{date.today().isoformat()}"`, format each candidate with `format_discovery_card`, join with `"\n\n"`, reply with HTML parse_mode
  - Wrap DB query in try/except, reply with error state `"\u274c Discovery scan data unavailable. The scanner may not have run yet today."` on failure

**2. Create `src/bot/handlers/duediligence.py` — /duediligence command (TBOT-11, D-15):**

```python
"""Handler for /duediligence command (TBOT-11).

Shows full due diligence report for IDX stocks. Reads from due_diligence_reports table.
Does NOT import pipeline modules (two-process boundary).
"""
```

- Import: `is_authorized`, `async_session_factory`, `Asset`, `DueDiligenceReport`, `OwnershipSnapshot`, `format_dd_report`
- `async def duediligence_handler(update, context)`:
  - Auth check
  - If no args: reply `"\u274c Please specify an IDX stock symbol. Example: /duediligence BBCA"` per UI-SPEC
  - `symbol = context.args[0].upper()`
  - Query Asset table for matching symbol (use `Asset.symbol.ilike(symbol)` or `ilike(f"{symbol}%")` to handle .JK suffix). Don't require watchlist membership -- DD works for any IDX stock
  - If asset not found or asset_type == "crypto": reply with crypto rejection `"\u2139\ufe0f Due diligence is not available for crypto assets -- use /report {symbol} for signal analysis."` per UI-SPEC
  - Query latest DueDiligenceReport for asset_id, ordered by report_date DESC, limit 1
  - If no DD report: reply empty state `"\U0001f4ca No due diligence data available for {SYMBOL}.\n\nDD data is refreshed weekly. If this is a new stock, data will be available after the next weekly scan."` per UI-SPEC
  - Load latest OwnershipSnapshot for asset to include ownership data
  - Build dd_data dict from DueDiligenceReport fields (sector_rank, management_quality, ownership_changes, competitive_position) + OwnershipSnapshot shareholders
  - Format with `format_dd_report(symbol, name, dd_data)`
  - Reply with HTML parse_mode

**3. Create `src/bot/handlers/compare.py` — /compare command (TBOT-10, D-16, D-17):**

```python
"""Handler for /compare command (TBOT-10).

Side-by-side sector comparison for IDX stocks. Reads from stock_fundamentals table.
Does NOT import pipeline modules (two-process boundary).
"""
```

- Import: `is_authorized`, `async_session_factory`, `Asset`, `StockFundamental`, `format_compare_table`
- Import `IDX_SECTOR_MAP` from `src.engines.valuation` (OK for bot -- it's a static dict, not pipeline code)
- `async def compare_handler(update, context)`:
  - Auth check
  - If no args or len < 2: reply `"\u274c Please specify 2-5 IDX stock symbols. Example: /compare BBCA BBRI BMRI"` per UI-SPEC
  - If len > 5: reply `"\u274c Maximum 5 symbols per comparison. Example: /compare BBCA BBRI BMRI"` per UI-SPEC
  - Parse symbols: `symbols = [a.upper() for a in context.args[:5]]`
  - Query Asset table for each symbol
  - Separate stock and crypto assets. If any crypto: prepend warning `"\u26a0\ufe0f Skipping crypto assets: {list}. /compare works with IDX stocks only."` per UI-SPEC
  - If <2 stock symbols remain after filtering: reply `"\u274c Please specify at least 2 symbols to compare. Example: /compare BBCA BBRI"` per UI-SPEC
  - For each stock asset, query latest StockFundamental record
  - Determine sector: use IDX_SECTOR_MAP for first symbol's sector, or "Mixed" if different sectors
  - Compute sector median from StockFundamental table for that sector (query all sector peers)
  - Build data list: `[{"symbol": s, "pe": f.pe_ratio, "pb": f.pb_ratio, "roe": f.roe, "net_margin": f.net_margin, "debt_to_equity": f.debt_to_equity, "revenue_cagr": None}]` -- revenue_cagr from FinancialData if available, else None
  - Format with `format_compare_table(symbols, data, sector)`
  - Reply with HTML parse_mode
  - If response >4096 chars, use split_report
