Create `src/data/discovery.py` with the following structure:

**Constants:**
```python
BATCH_SIZE = 80
BATCH_DELAY = 3.0  # seconds between yfinance batches
SCAN_TIMEOUT = 300  # 5 min hard timeout
TOP_N = 20  # store top 20 candidates (report shows top 5)

TRIGGER_WEIGHTS = {
    "volume_spike": 0.30,
    "price_breakout": 0.30,
    "momentum_surge": 0.25,
    "statistical_anomaly": 0.15,
}
```

**Functions:**

1. `compute_composite_score(triggers: dict[str, float]) -> float` — Weighted sum of trigger scores. Apply 1.15x bonus for 2 active triggers, 1.30x for 3+. Cap at 1.0.

2. `_detect_volume_spike(volumes: pd.Series) -> float` — Compare last day's volume to 20-day average. Returns normalized score 0-1. Threshold: >2x avg = trigger (score = min(1.0, ratio/5.0) for gradual scaling). Returns 0.0 if insufficient data (<20 days).

3. `_detect_breakout(closes: pd.Series, highs: pd.Series) -> float` — Check for: (a) 52-week high (close >= max of last 252 days), (b) Bollinger upper band break. Use pandas-ta-classic for Bollinger (`df.ta.bbands(length=20)`). Returns max of individual breakout scores (0-1). Import pandas_ta at module level.

4. `_detect_momentum(closes: pd.Series) -> float` — Check RSI crossover above 50 (was below, now above) and MACD signal crossover (MACD crosses above signal). Use pandas-ta-classic `ta.rsi(length=14)` and `ta.macd()`. Return max of momentum scores.

5. `_detect_anomaly(closes: pd.Series, volumes: pd.Series) -> float` — Z-score based: compute rolling 20-day mean/std of returns, flag if today's return Z-score > 2.0 std devs. Returns normalized score.

6. `_detect_triggers(closes: pd.Series, highs: pd.Series, volumes: pd.Series) -> dict[str, float]` — Calls all four detect functions, returns dict with non-zero triggers.

7. `_fetch_idx_screening_data(tickers: list[str]) -> pd.DataFrame` — Download 1-month OHLCV for all tickers using `yf.download()` in batches of 80. Wrap in `run_in_executor` since yfinance is synchronous. Add BATCH_DELAY between batches. Return concatenated DataFrame grouped by ticker.

8. `_get_ihsg_tickers() -> list[str]` — Return list of all IHSG tickers. Initially: try fetching from IDX API endpoint `https://www.idx.co.id/primary/StockData/GetSecurityStock?start=0&length=9999&code=&sector=&board=`. If fails, fall back to a hardcoded list of ~100 major tickers (the IDX_SECTOR_MAP keys + additional large-cap stocks). All tickers must have `.JK` suffix for yfinance.

9. `_fetch_crypto_screening_data() -> list[dict]` — Single httpx GET to `https://api.coingecko.com/api/v3/coins/markets` with params `vs_currency=usd, order=market_cap_desc, per_page=100, page=1, sparkline=false, price_change_percentage=24h,7d`. Return JSON list.

10. `_score_crypto_candidate(coin: dict) -> dict[str, float]` — Score crypto based on: volume_spike (market_cap_change_percentage_24h magnitude), momentum_surge (price_change_percentage_24h > 10%), statistical_anomaly (7d vs 24h divergence). Return triggers dict.

11. `async def run_discovery_scan(session: AsyncSession, run_date: date) -> list[dict]` — Main entry point. Orchestrates IDX + crypto scanning with asyncio.wait_for timeout of SCAN_TIMEOUT seconds. Steps:
    - Fetch IDX screening data in batches
    - For each ticker with sufficient data, detect triggers
    - Compute composite scores
    - Fetch crypto screening data
    - Score crypto candidates
    - Combine and sort by composite_score desc
    - Take top N candidates
    - Persist as DiscoveryCandidate rows (delete old rows for same scan_date first, then insert)
    - Return list of dicts for report formatter consumption
    - Wrap entire function in try/except, log errors, return empty list on failure

Use structlog for logging. All external calls must be wrapped in try/except with graceful degradation (if IDX scan fails, still try crypto; if crypto fails, still return IDX results).
