```python
"""IDX ownership/disclosure filing scraper.

Fetches shareholder composition from idx.co.id disclosure filings.
Reuses httpx patterns from idx_doc_fetcher.py. Weekly refresh cycle (D-12).
"""
```

Functions:
1. `async def fetch_ownership_data(session: AsyncSession, asset: Asset) -> dict | None` — Main entry. Checks if OwnershipSnapshot exists for this week already (weekly refresh D-12). If yes, return existing data. If no, scrape IDX. Try endpoint `https://www.idx.co.id/primary/ListedCompany/GetShareHolder?KodeEmiten={symbol_without_JK}&start=0&length=100`. Parse JSON response. Store as OwnershipSnapshot. Return shareholders dict. On HTTP error or parse failure, log warning and return None.

2. `_parse_shareholder_response(data: dict) -> dict` — Extract shareholder list from IDX API response. Return `{"shareholders": [{"name": str, "pct": float}], "public_float_pct": float, "total_shares": float}`.

3. `_compute_ownership_changes(current: dict, previous: dict | None) -> dict | None` — Compare current vs previous snapshot. Flag changes where holder pct changed by >2pp. Return `{"major_changes": [{"name": str, "old_pct": float, "new_pct": float, "direction": "increase"|"decrease"}], "public_float_change": float}`.

Use IDX_HEADERS from idx_doc_fetcher pattern. Use structlog. All httpx calls wrapped in try/except.

**Create `src/data/due_diligence.py`:**

```python
"""Due diligence computation for IDX stocks.

Computes sector benchmarking (DUED-01), management quality (DUED-03),
competitive positioning (DUED-04), and generates DD flags for LLM injection.
All data sourced from existing StockFundamental and FinancialData tables.
"""
```

Functions:

1. `async def compute_sector_benchmark(session: AsyncSession, asset: Asset, sector: str) -> dict | None` — Query all StockFundamental records for assets in the same sector (via IDX_SECTOR_MAP). Compute sector medians for P/E, P/B, ROE, net_margin, debt_to_equity. Compare company values vs medians. Return dict:
```python
{
    "pe": {"value": 12.3, "median": 15.1, "vs_median": -18.5, "position": "below"},
    "pb": {"value": 2.1, "median": 1.8, "vs_median": 16.7, "position": "above"},
    "roe": {"value": 18.5, "median": 12.0, "vs_median": 54.2, "position": "above"},
    "net_margin": {"value": 28.3, "median": 22.0, "vs_median": 28.6, "position": "above"},
    "debt_to_equity": {"value": 0.8, "median": 1.2, "vs_median": -33.3, "position": "below"},
    "rank": 3,
    "of": 12,
}
```
Position logic: >10% above median = "above", within 10% = "at_median", >10% below = "below". For D/E ratio, invert (lower is better per UI-SPEC). Rank = company position when sorted by ROE descending within sector.

2. `def compute_management_quality(financial_records: list[FinancialData]) -> dict` — Per D-09 and RESEARCH.md code example. Compute from FinancialData records:
   - Revenue CAGR (40% weight): extract revenue records, compute CAGR over available period. Score: cagr/0.15 capped 0-1 (15%+ CAGR = perfect).
   - ROE trend (30% weight): average of last 4 quarters ROE / 20.0, capped 0-1.
   - Capital allocation (30% weight): net_profit / total_equity trend, default 0.5 if insufficient data.
   - Total score = weighted sum. Labels: >0.7 "Excellent", >0.5 "Good", >0.3 "Fair", else "Weak".
   - Return `{"score": float, "label": str, "detail": {"revenue_cagr": float, "roe_score": float}}`.
   - If <4 records, return `{"score": 0.0, "label": "Insufficient data", "detail": {}}`.

3. `async def compute_competitive_position(session: AsyncSession, asset: Asset, sector: str) -> dict` — Query StockFundamental for all sector peers. Rank by composite of ROE + revenue_growth + net_margin. Return:
```python
{
    "rank": 3,
    "of": 12,
    "metric": "ROE-weighted composite",
    "moat_indicators": ["High ROE vs peers", "Consistent margins"]  # derived from data
}
```
Moat indicators: "High ROE vs peers" if ROE > 1.5x sector median; "Consistent margins" if net_margin > sector median; "Low leverage" if D/E < 0.5x sector median.

4. `def generate_dd_flags(sector_bench: dict | None, mgmt_quality: dict | None, ownership_changes: dict | None) -> list[dict]` — Generate DD flags for LLM consumption (D-18):
   - Ownership decrease >5pp by any major holder -> `{"type": "insider_selling", "severity": "warning", "message": "..."}`
   - Management score <0.3 -> `{"type": "weak_management", "severity": "warning", "message": "..."}`
   - P/E >50% above sector median -> `{"type": "overvaluation_risk", "severity": "info", "message": "..."}`
   - D/E >2x sector median -> `{"type": "high_leverage", "severity": "warning", "message": "..."}`
   - Return empty list if no flags triggered.

5. `async def compute_dd_report(session: AsyncSession, asset: Asset, run_date: date) -> DueDiligenceReport | None` — Main orchestrator. Checks weekly cache (D-12). If cached report exists for this week, return it. Otherwise:
   - Look up sector from IDX_SECTOR_MAP
   - Compute sector benchmark
   - Load FinancialData and compute management quality
   - Fetch ownership data (calls ownership_fetcher)
   - Compute ownership changes vs previous snapshot
   - Compute competitive position
   - Generate DD flags
   - Store as DueDiligenceReport row (UPSERT on asset_id + report_date)
   - Return the report
   - If asset not in IDX_SECTOR_MAP, still compute what's possible (management quality from FinancialData, skip sector bench).
