1. Create `monitoring/prometheus/prometheus.yml` (per D-03, Research scrape config):

```yaml
global:
  scrape_interval: 15s
  evaluation_interval: 15s

scrape_configs:
  - job_name: 'bot'
    static_configs:
      - targets: ['bot:8000']
    metrics_path: /metrics/

  - job_name: 'pushgateway'
    honor_labels: true
    static_configs:
      - targets: ['pushgateway:9091']

  - job_name: 'node_exporter'
    static_configs:
      - targets: ['172.17.0.1:9100']

  - job_name: 'prometheus'
    static_configs:
      - targets: ['localhost:9090']
```

NOTE: Per Pitfall 5, metrics_path for bot MUST be `/metrics/` (trailing slash) because FastAPI mount redirects `/metrics` to `/metrics/`. node_exporter uses Docker host IP `172.17.0.1` since it runs with `network_mode: host` and binds to `127.0.0.1:9100`. Prometheus needs the Docker bridge gateway IP to reach it.
