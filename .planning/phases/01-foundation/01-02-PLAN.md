    Define `class PipelineRunner`:
    - `__init__(self, session_factory: async_sessionmaker)` — stores session factory and structlog logger
    - `async def run_pipeline(self, run_date: date, stages: list[str] | None = None, rerun_failed: bool = False) -> list[StageResult]`:
      - Default stages: ["fetch", "analyze", "decide", "report"] (evaluate is separate, per ARCHITECTURE.md daily flow)
      - For each stage, call `run_stage()`
      - Return list of StageResults
    - `async def run_stage(self, run_date: date, stage: str, stage_func: StageFunc, rerun_failed: bool = False) -> StageResult`:
      - Check if PipelineRun exists for (run_date, stage)
      - If exists and status="completed" and not rerun_failed: return early (idempotent)
      - If exists and status in ("partial", "failed") or rerun_failed: load existing run, find incomplete assets
      - If not exists: create PipelineRun with status="running", create PipelineAssetRun for each active asset
      - Query active assets from db
      - For each asset not already completed:
        - Set PipelineAssetRun status="running", started_at=now
        - Call stage_func with per-asset timeout (use `asyncio.wait_for` with timeout from settings based on stage name: fetch=60s, analyze=120s, llm=30s, default=60s)
        - On success: set status="completed", completed_at=now
        - On timeout: set status="failed", error_message="Timeout after {N}s"
        - On SourceCriticalError: set status="skipped", error_message=str(error)
        - On other Exception: set status="failed", error_message=str(error), increment retry_count
        - Continue to next asset regardless of failure
      - After all assets: update PipelineRun status to "completed" (if all succeeded) or "partial" (if any failed/skipped)
      - Set PipelineRun completed_at=now
      - Return StageResult with counts
    - `def _get_timeout(self, stage: str) -> int`: returns timeout_fetch for "fetch", timeout_analyze for "analyze", timeout_llm for "decide", 60 for default
