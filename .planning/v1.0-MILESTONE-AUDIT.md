## Cross-Phase Integration Issues

### Issue 1: `reflect` stage skipped on standard pipeline runs (BREAKING)

- **File:** `src/pipeline/runner.py` line 71
- **Problem:** Hardcoded default `stages = ["evaluate", "fetch", "analyze", "decide", "report"]` does not include `"reflect"`. The stage is registered in `main.py` but never runs on unconstrained pipeline invocations.
- **Impact:** Lesson extraction (EVAL-02) and feedback loop silently skipped
- **Fix:** Add `"reflect"` to default stages; remove `"report"` (not a StageFunc)
- **Affected requirements:** EVAL-02, EVAL-03, EVAL-04, LLM-04

### Issue 2: 5 Prometheus metrics defined but never emitted (MODERATE)

- **File:** `src/monitoring/metrics.py`
- **Orphaned:** `FETCH_SUCCESS`, `FETCH_FAILURE`, `ENGINE_DURATION`, `DATA_FRESHNESS_HOURS`, `BOT_REQUEST_COUNT`
- **Impact:** Grafana dashboard panels for fetch rate, engine duration, data freshness show no data. The `data_freshness_hours` alert rule will never fire.
- **Fix:** Instrument fetchers, engine analyze calls, and bot webhook with these metrics
- **Affected requirements:** MON-09, MON-10

### Issue 3: `reflect` stage timeout not mapped (MINOR)

- **File:** `src/pipeline/runner.py`, `_get_timeout()` method
- **Problem:** `timeout_reflect = 120` defined in `config.py` but not in runner's timeout dict — falls to 60s default
- **Fix:** Add `"reflect": settings.timeout_reflect` to timeouts dict
